claude-mon

A desk display for Claude Code: session and weekly usage, context, a pace forecast, Anthropic's service status, and a heads-up when Claude is waiting on you.

1

Flash the board and connect it to Wi-Fi

Plug the board into this computer with a data cable (on two-port boards, use the micro-USB port), pick your board, then click Connect to Wi-Fi when asked. Use Chrome or Edge on a desktop.

Most common Two USB ports USB-C and micro-USB side by side (often sold as "CYD2USB"). Your browser can't flash boards. Open this page in Chrome or Edge on a computer. This page needs to be opened over HTTPS.
Original One USB port A single micro-USB port. Use Chrome or Edge on a computer. This page needs to be opened over HTTPS.

Not sure? Try "Two USB ports" first. If the screen stays dark or the colours look wrong, install the other one; your settings are kept.

Once the board is on Wi-Fi it shows a six-digit code. It's how your PC proves it's yours. To show a new code later, hold your finger on the screen for 3 seconds.

3

Set up Claude Code on your PC

Open PowerShell and run this. It finds the board, asks for the code, and adds a status line and hooks to Claude Code. Then restart Claude Code.

irm https://magnuskeel.github.io/claude-mon/install.ps1 | iex

Prefer to read it first? Download install.ps1, then run powershell -ExecutionPolicy Bypass -File install.ps1. It copies four small scripts to %LOCALAPPDATA%\claude-mon and backs up your settings before changing them. Nothing runs in the background.

Help

The board doesn't show up when I click Install

Try another cable (many are charge-only), and on two-port boards use the micro-USB port. On Windows you may need the CH340 driver or the CP210x driver, depending on the chip next to the USB port.

I can't use the Wi-Fi step in the browser

The board also opens its own Wi-Fi network called claude-mon-setup. Join it from your phone and a setup page opens where you pick your network. The board only supports 2.4 GHz Wi-Fi.

The installer can't find the board

Make sure the PC and the board are on the same network. The board's address is shown on its screen; type it in when the installer asks.

Start over or move to a new network

Hold the BOOT button on the board for 5 seconds. It forgets its Wi-Fi and pairing and shows the setup screen again.

Uninstall from the PC

Run powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\claude-mon\uninstall.ps1". It removes only claude-mon's hooks and status line and deletes its folder.
